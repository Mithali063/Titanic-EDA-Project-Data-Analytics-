# Titanic-EDA-Project-Data-Analytics-
Exploratory Data Analysis on Titanic Dataset
**📌 Objective**
Perform Exploratory Data Analysis on Titanic dataset to find patterns and insights.
**📂 Dataset**
Source: Kaggle Titanic Dataset
**🔍 Key Analysis**
Age distribution
Survival rate by class
Fare vs Class
Correlation heatmap
**📈 Key Insights**
Higher class passengers had higher survival rate
Fare is strongly related to class
Age has less impact on survival
**🚀 How to Run**
pip install -r requirements.txt
jupyter notebook
